# อ่านแบบ 2D·3D·4D

แอปอ่านแบบก่อสร้าง ใช้งานออฟไลน์ได้บน iPhone

## วิธีเปิดบน iPhone (Safari)

1. เปิดลิงก์นี้ใน Safari: https://nattakanworks-bot.github.io/Drawing-app/
2. แตะปุ่ม **แชร์** (Share)
3. เลือก **เพิ่มไปที่หน้าจอโฮม** (Add to Home Screen) แล้วแตะเพิ่ม
4. เปิดแอปจากไอคอนบนหน้าจอโฮม หลังจากเปิดครั้งแรกแล้ว ใช้งานออฟไลน์ได้

## ความสามารถใหม่

- ปุ่ม **เลือกประเภทงาน** สำหรับเลือกสาขางานก่อนเริ่ม
- มุมมอง 3D และ 4D แยกตามสาขา เช่น งานท่อ (piping) งานปิโตรเลียม และสาขาอื่น
- วาล์วขนาดจริงตามมาตรฐาน ASME
- ปุ่ม **แปลง 2D → 3D** และ **แปลง 3D → 4D** พร้อมแถบขั้นตอนการแปลง
- อ่านแบบท่อไอโซเมตริก พร้อมป้ายขนาดในมุมมอง 3D และ 4D
- ตรวจจับชนิดมุมมองของแบบ และมาตรฐานสากล
- ปุ่ม **ประกอบแบบเป็นโมเดล** พร้อมแผ่นแบบเป็นช่อง และการเพิ่มแผ่น
- **โหมดเรียนรู้** รวม 10 ฟีเจอร์สำหรับผู้เริ่มต้น
- พิมพ์ได้ทั้งสีและขาวดำ
