# อ่านแบบ 2D·3D·4D

แอปอ่านแบบก่อสร้าง ใช้งานออฟไลน์ได้บน iPhone

## วิธีเปิดบน iPhone (Safari)

1. เปิดลิงก์นี้ใน Safari: https://nattakanworks-bot.github.io/Drawing-app/
2. แตะปุ่ม **แชร์** (Share)
3. เลือก **เพิ่มไปที่หน้าจอโฮม** (Add to Home Screen) แล้วแตะเพิ่ม
4. เปิดแอปจากไอคอนบนหน้าจอโฮม หลังจากเปิดครั้งแรกแล้ว ใช้งานออฟไลน์ได้
